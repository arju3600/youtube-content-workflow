# YouTube Video Production Checklist 🎬

A practical checklist for taking a YouTube video from initial research to publishing and post-publish analysis.

## 🔍 1. Research & Topic Validation

- [ ] Define the main video topic
- [ ] Identify the target audience
- [ ] Research audience search intent
- [ ] Analyze relevant competitor videos
- [ ] Review high-performing titles
- [ ] Study competitor thumbnails
- [ ] Collect reliable source materials
- [ ] Confirm the topic has enough value for the audience

## 📝 2. Content Planning

- [ ] Define the core promise of the video
- [ ] Organize research materials
- [ ] Create the content structure
- [ ] Identify the strongest hook
- [ ] Plan important story/content sections
- [ ] Prepare required visual and audio assets

## ✍️ 3. Script & Story Development

- [ ] Write a strong opening hook
- [ ] Keep the narrative clear and easy to follow
- [ ] Remove unnecessary repetition
- [ ] Improve pacing and transitions
- [ ] Verify important facts and details
- [ ] Review the script for audience retention
- [ ] Prepare the final voiceover version

## 🎙️ 4. Production

- [ ] Record or generate the final voiceover
- [ ] Check voice clarity, pacing, and pronunciation
- [ ] Organize footage and assets
- [ ] Complete the main video edit
- [ ] Add relevant sound effects and music
- [ ] Check audio levels
- [ ] Review visual pacing
- [ ] Watch the complete video before export
- [ ] Export the final master file

## 📈 5. YouTube SEO

- [ ] Identify the primary keyword/topic
- [ ] Analyze search intent
- [ ] Create multiple title options
- [ ] Select the strongest accurate title
- [ ] Write an optimized description
- [ ] Add relevant metadata where useful
- [ ] Check that title and description accurately represent the video

## 🖼️ 6. Thumbnail & Packaging

- [ ] Define one clear thumbnail concept
- [ ] Make the main subject easy to recognize
- [ ] Check readability on mobile
- [ ] Avoid unnecessary visual clutter
- [ ] Make sure the thumbnail complements the title
- [ ] Avoid misleading clickbait
- [ ] Compare the final packaging against competing videos

## 🚀 7. Pre-Publish Quality Control

- [ ] Confirm final video file is correct
- [ ] Check title
- [ ] Check description
- [ ] Check thumbnail
- [ ] Check visibility and scheduling settings
- [ ] Check playlist/category settings where relevant
- [ ] Review copyright/checks information
- [ ] Verify the video plays correctly

## 📊 8. Post-Publish Review

- [ ] Monitor impressions
- [ ] Review click-through rate (CTR)
- [ ] Review audience retention
- [ ] Check average view duration
- [ ] Read useful viewer feedback
- [ ] Identify major drop-off points
- [ ] Record lessons for the next video
- [ ] Test packaging changes only when supported by performance data

---

## Core Principle

**Research → Plan → Create → Package → Publish → Measure → Improve**

The purpose of this checklist is not to complete more steps. It is to reduce avoidable mistakes and make each video better than the last.
